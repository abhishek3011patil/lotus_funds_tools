# License provenance

These files contain the complete upstream license texts for the local neural speech components.

- `kokoro-model-Apache-2.0.txt`: [Apache's canonical Apache 2.0 license](https://www.apache.org/licenses/LICENSE-2.0.txt). The [Kokoro-82M model card](https://huggingface.co/hexgrad/Kokoro-82M) declares `apache-2.0`.
- `kokoro-onnx-MIT.txt`: copied unchanged from the installed `kokoro-onnx==0.6.1` wheel's `licenses/LICENSE`.
- `espeakng-loader-MIT.txt`: [upstream loader license](https://raw.githubusercontent.com/thewh1teagle/espeakng-loader/main/LICENSE). This MIT license applies to the loader, not to its bundled eSpeak NG library.
- `espeak-ng-GPL-3.0.txt`: [eSpeak NG 1.52.0 COPYING](https://raw.githubusercontent.com/espeak-ng/espeak-ng/1.52.0/COPYING).
- `phonemizer-GPL-3.0.txt`: copied unchanged from the installed `phonemizer==3.4.0` wheel's `licenses/LICENSE`.

Component attribution, versions, source locations, and model integrity information are recorded in `THIRD_PARTY_NOTICES.md` at the application root.
